# Eco City Simulator - OOP C++ Application

![C++](https://img.shields.io/badge/C%2B%2B-00599C?style=for-the-badge&logo=cplusplus&logoColor=white)

An object-oriented simulation application in C++ designed to model an ecologically balanced city, balancing energy resources, pollution, municipal budgets, and citizen happiness.

## Key Features
*   **Object-Oriented Architecture**: Utilizes inheritance, polymorphism, and encapsulated classes to model city nodes (Residential, Commercial, Industrial, Green Zones).
*   **Resource Management Simulation**: Models power grids, water supply, and garbage processing limits.
*   **Dynamic Events**: Generates random weather events, budget fluctuations, and population shifts.
*   **Interactive CLI**: Terminal-based user interface detailing current stats, news feeds, and logs.

## File Structure
```text
├── hassan_final.cpp          # Main simulation codebase
├── Submission.cpp            # Project submission wrappers
├── eco_city_instructions.txt # Setup and operations documentation
└── test.cpp                  # Unit testing playground
```

## Setup & Execution
Compile the codebase using any standard C++ compiler:
```bash
# Compile
g++ -o eco_city hassan_final.cpp

# Run
./eco_city
```
